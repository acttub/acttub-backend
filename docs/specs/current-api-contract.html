Acttub Backend API 요청/응답 명세

현재 코드의 Controller, DTO, Service 검증 로직, 전역 예외 핸들러, 통합 테스트를 기준으로 정리한 명세입니다.

공통 규칙

  • 성공 응답은 항상 {"data": ...} 래퍼를 사용합니다.
  • 오류 응답은 항상 {"error": {"code", "message", "details"}} 래퍼를 사용합니다.
  • 시간 필드는 OffsetDateTime으로 직렬화됩니다. 예: 2026-06-20T18:10:00+09:00
  • ID 필드는 응답에서 문자열로 내려갑니다. 예: "coachingId": "1"
  • 응답 본문은 JSON입니다.

성공 응답 래퍼

{
  "data": {}
}

오류 응답 래퍼

{
  "error": {
    "code": "ERROR_CODE",
    "message": "Error message.",
    "details": {}
  }
}

POST/api/v1/coachings

연기 영상과 장면 맥락을 업로드해 코칭 피드백을 생성합니다.

요청

항목 값
Content-Type multipart/form-data
파일 크기 제한 100MB, 104857600 bytes
허용 영상 MIME type video/mp4, video/quicktime, video/webm

iPhone 기본 카메라 영상은 보통 .MOV 파일이며 MIME type은 video/quicktime으로 들어옵니다. 고효율성 설정에서는 내부 코덱이 HEVC/H.265일 수 있습니다. Android 기본 카메라 영상은 보통 .mp4 파일이며 MIME type은 video/mp4입니다.

필드 타입 필수 검증/정규화
video file 예 크기가 0보다 커야 하고, MIME type은 허용 목록 중 하나여야 합니다.
genre string 예 연극, 영화, 뮤지컬, 드라마, 기타 중 하나입니다. 앞뒤 공백은 제거됩니다.
customGenre string 조건부 genre=기타일 때 필수입니다. genre가 기타가 아니면 서버에서 null로 정규화합니다.
situation string 예 장면 상황입니다. 앞뒤 공백 제거 후 빈 값이면 유효하지 않습니다.
characterSetting string 예 인물 설정입니다. 앞뒤 공백 제거 후 빈 값이면 유효하지 않습니다.
subtext string 아니오 서브텍스트입니다. 생략, 빈 문자열, 공백 문자열은 null로 정규화됩니다.

요청 예시

curl -X POST http://localhost:8080/api/v1/coachings \
  -F "video=@scene.mp4;type=video/mp4" \
  -F "genre=영화" \
  -F "situation=헤어진 연인을 우연히 다시 만난 상황" \
  -F "characterSetting=감정을 쉽게 드러내지 않는 배우 지망생" \
  -F "subtext=아직 미련이 있지만 괜찮은 척한다"

status는 도메인 상태값이며 현재 응답 예시는 정상 완료 기준 COMPLETED입니다. 도메인에는 ANALYZING, COMPLETED, FAILED가 있습니다.

오류 응답

HTTP code message details 예시 조건
400 INVALID_COACHING_REQUEST Invalid coaching request. {"fields":["video","genre","customGenre","situation","characterSetting"]} 필수 multipart 필드가 없거나, 값이 비어 있거나, 허용 값/파일 조건을 만족하지 않습니다.
413 PAYLOAD_TOO_LARGE Uploaded video is too large. {"maxSizeBytes":104857600} 영상 또는 multipart 요청이 100MB를 초과합니다.
415 UNSUPPORTED_MEDIA_TYPE Unsupported media type. {"contentType":"application/json"} multipart/form-data가 아닌 요청입니다.
500 VIDEO_STORAGE_FAILED Video storage failed. {"coachingId":"{createdCoachingId}","status":"FAILED"} 영상 저장 중 예외가 발생했습니다. coachingId는 실패 전에 생성된 실제 코칭 ID입니다.
502 AI_ANALYSIS_FAILED Coaching analysis failed. {"coachingId":"{createdCoachingId}","status":"FAILED"} AI 분석 중 예외가 발생했습니다. coachingId는 실패 전에 생성된 실제 코칭 ID입니다.
504 AI_ANALYSIS_TIMEOUT Coaching analysis timed out. {"coachingId":"{createdCoachingId}","status":"FAILED"} AI 분석이 제한 시간 안에 끝나지 않았습니다. coachingId는 실패 전에 생성된 실제 코칭 ID입니다.

POST/api/v1/coachings/{coachingId}/evaluation

완료된 코칭 결과에 사용자 평가를 등록합니다. 코칭 하나당 평가는 한 번만 등록할 수 있습니다.

요청

항목 값
Content-Type application/json
Path variable coachingId: long
필드 타입 필수 검증/정규화
rating integer 예 1 이상 5 이하입니다.
comment string 아니오 null, 빈 문자열, 공백 문자열은 저장/응답 시 null로 정규화됩니다.

요청 예시

{
  "rating": 4,
  "comment": "감정 흐름은 좋았고 발성 조언은 더 구체적이면 좋겠습니다."
}

201 응답

{
  "data": {
    "evaluationId": "1",
    "coachingId": "1",
    "rating": 4,
    "comment": "감정 흐름은 좋았고 발성 조언은 더 구체적이면 좋겠습니다.",
    "createdAt": "2026-06-20T18:12:00+09:00"
  }
}

오류 응답

HTTP code message details 예시 조건
400 INVALID_EVALUATION_REQUEST Invalid evaluation request. {"fields":["body","rating"]} 요청 본문이 없거나 JSON으로 읽을 수 없거나, rating이 없거나 1~5 범위를 벗어났습니다.
400 INVALID_COACHING_ID Invalid coaching id. {"coachingId":"abc"} coachingId path 값이 long으로 변환되지 않습니다.
404 COACHING_NOT_FOUND Coaching not found. {"coachingId":"999"} 해당 ID의 코칭이 없습니다.
409 COACHING_NOT_EVALUABLE Only completed coachings can be evaluated. {"coachingId":"{coachingId}","status":"FAILED"} 코칭 상태가 COMPLETED가 아닙니다.
409 COACHING_EVALUATION_ALREADY_EXISTS Coaching evaluation already exists. {"coachingId":"{coachingId}"} 이미 평가가 등록된 코칭입니다.
415 UNSUPPORTED_MEDIA_TYPE Unsupported media type. {"contentType":"text/plain"} application/json이 아닌 요청입니다.

현재 구현되지 않은 조회 API

  • GET /api/v1/coachings/{coachingId}는 Controller에 없으므로 404를 반환합니다.
