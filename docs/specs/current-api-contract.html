Acttub Backend 전체 API 명세

SOMA-152 코칭 챗봇형 진단 목표 API 계약입니다. 사용자는 영상 업로드 후 AI와 최소 3턴, 최대 7턴 대화하며 연기 의도와 상황을 구체화하고, 대화가 충분해지면 최종 진단을 생성합니다.

Base URL: http://localhost:8080 응답 포맷: JSON 문서 기준일: 2026-06-28 대화 정책: min 3 / max 7 turns

목차

  • 공통 규칙
  • 공통 스키마
  • POST /api/v1/coachings
  • POST /api/v1/coachings/{coachingId}/messages
  • POST /api/v1/coachings/{coachingId}/diagnosis
  • POST /api/v1/coachings/{coachingId}/evaluation
  • POST /api/v1/waitlist
  • 오류 코드 목록

공통 규칙

  • 성공 응답은 항상 {"data": ...} 래퍼를 사용합니다.
  • 오류 응답은 항상 {"error": {"code", "message", "details"}} 래퍼를 사용합니다.
  • ID 필드는 응답에서 문자열로 내려갑니다. 예: "coachingId": "1"
  • 시간 필드는 OffsetDateTime으로 직렬화됩니다. 예: 2026-06-28T02:10:00+09:00
  • null 필드는 응답 JSON에서 생략될 수 있습니다.

성공 응답 래퍼

{
  "data": {}
}

오류 응답 래퍼

{
  "error": {
    "code": "ERROR_CODE",
    "message": "Error message.",
    "details": {}
  }
}

코칭 상태값

상태 의미 클라이언트 동작
ANALYZING 영상 저장 또는 AI 초기 분석 중인 내부 상태입니다. 일반 성공 응답으로는 노출되지 않습니다.
QUESTION_READY 첫 AI 질문이 준비된 상태입니다. /messages에 첫 답변을 제출합니다.
IN_CONVERSATION 다음 AI 질문이 있고 사용자 답변을 기다리는 상태입니다. /messages에 다음 답변을 제출합니다.
READY_FOR_DIAGNOSIS 최소 3턴 이후 AI가 충분하다고 판단했거나 최대 7턴에 도달한 상태입니다. /diagnosis를 호출합니다.
COMPLETED 최종 진단과 피드백 카드가 생성된 상태입니다. 평가 등록이 가능합니다.
FAILED 영상 저장, AI 분석, 대화, 진단 중 실패한 상태입니다. 진단 또는 평가를 진행할 수 없습니다.

엔드포인트 요약

Method Path Content-Type 성공 HTTP 설명
POST /api/v1/waitlist application/json 201 비공개 테스트 사전 등록 이메일과 선택 정보를 저장합니다.
POST /api/v1/coachings multipart/form-data 201 영상과 장면 정보를 업로드하고 초기 분석과 첫 질문을 생성합니다.
POST /api/v1/coachings/{coachingId}/messages application/json 201 현재 질문에 대한 답변을 제출하고 다음 질문 또는 진단 준비 상태를 받습니다.
POST /api/v1/coachings/{coachingId}/diagnosis 없음 또는 application/json 201 누적 대화 컨텍스트로 최종 진단을 생성합니다.
POST /api/v1/coachings/{coachingId}/evaluation application/json 201 완료된 코칭 결과에 사용자 평가를 등록합니다.

POST/api/v1/coachings

연기 영상과 장면 맥락을 업로드해 첫 질문을 포함한 QUESTION_READY 코칭을 생성합니다.

요청

필드 타입 필수 검증/정규화
video file 예 0보다 큰 파일. MIME type은 video/mp4, video/quicktime, video/webm. 최대 100MB.
genre string 예 연극, 영화, 뮤지컬, 드라마, 기타 중 하나입니다.
customGenre string 조건부 genre=기타일 때 필수입니다. 장르가 기타가 아니면 서버에서 null로 정규화합니다.
situation string 예 장면 상황입니다. 앞뒤 공백 제거 후 빈 값이면 유효하지 않습니다.
characterSetting string 예 인물 설정입니다. 앞뒤 공백 제거 후 빈 값이면 유효하지 않습니다.
subtext string 아니오 생략, 빈 문자열, 공백 문자열은 null로 정규화됩니다.

요청 예시

curl -X POST http://localhost:8080/api/v1/coachings \
  -F "video=@scene.mp4;type=video/mp4" \
  -F "genre=영화" \
  -F "situation=헤어진 연인을 우연히 다시 만난 상황" \
  -F "characterSetting=감정을 쉽게 드러내지 않는 배우 지망생" \
  -F "subtext=아직 미련이 있지만 괜찮은 척한다"

POST/api/v1/waitlist

비공개 테스트 오픈 안내를 받을 이메일을 사전 등록합니다.

요청

{
  "email": "you@example.com",
  "actorStatus": "배우 지망생",
  "helpTopic": "대본 분석",
  "consent": true,
  "website": ""
}
필드 타입 필수 검증/정규화
email string 예 이메일 형식이어야 하며, 소문자로 정규화해 저장합니다.
actorStatus string 아니오 연기 입시 준비 중, 연극영화과 재학 중, 배우 지망생, 현역 배우, 취미로 연기 연습 중, 기타 중 하나입니다.
helpTopic string 아니오 대본 분석, 인물의 목적 찾기, 이전 상황 감정 정리, 현재 감정선 정리, 서브텍스트 정리, 기타 중 하나입니다.
consent boolean 예 true여야 저장합니다.
website string 아니오 봇 방지용 honeypot 필드입니다. 값이 있으면 저장하지 않고 성공처럼 응답합니다.

201 응답

{
  "data": {
    "accepted": true,
    "waitlistId": "1",
    "email": "you@example.com",
    "actorStatus": "배우 지망생",
    "helpTopic": "대본 분석",
    "createdAt": "2026-06-28T02:09:00+09:00"
  }
}

201 응답: honeypot

{
  "data": {
    "accepted": true
  }
}

POST/api/v1/coachings/{coachingId}/messages

현재 AI 질문에 대한 사용자 답변을 제출합니다. 서버는 답변을 저장하고 다음 질문 또는 진단 준비 상태를 반환합니다.

요청

{
  "answer": "아직 미련이 있다는 걸 들키고 싶지 않았습니다."
}

201 응답: 다음 질문

{
  "data": {

    "createdAt": "2026-06-28T02:10:00+09:00",

    },
    "conversation": {
      "turnIndex": 1,
      "minTurns": 3,
      "maxTurns": 7,
      "diagnosisReady": false,
      "reason": "최소 3턴 전이므로 의도 구체화를 계속합니다."

POST/api/v1/coachings/{coachingId}/evaluation

완료된 코칭 결과에 사용자 평가를 등록합니다. 코칭 하나당 평가는 한 번만 등록할 수 있습니다.

요청

{
  "rating": 4,
  "comment": "감정 흐름은 좋았고 발성 조언은 더 구체적이면 좋겠습니다."
}

201 응답

{
  "data": {
    "evaluationId": "1",
    "coachingId": "1",
    "rating": 4,
    "comment": "감정 흐름은 좋았고 발성 조언은 더 구체적이면 좋겠습니다.",
    "createdAt": "2026-06-28T02:14:00+09:00"
  }
}

오류 코드 목록

HTTP code 주요 발생 API 설명
400 INVALID_COACHING_REQUEST POST /api/v1/coachings 영상, 장르, 커스텀 장르, 상황, 인물 설정이 유효하지 않습니다.
400 INVALID_WAITLIST_REQUEST POST /api/v1/waitlist 이메일, 수집 동의, 선택값이 유효하지 않습니다.
400 INVALID_MESSAGE_REQUEST POST /api/v1/coachings/{coachingId}/messages 메시지 요청 본문 또는 답변이 유효하지 않습니다.
400 INVALID_EVALUATION_REQUEST POST /api/v1/coachings/{coachingId}/evaluation 평가 요청 본문 또는 평점이 유효하지 않습니다.
400 INVALID_COACHING_ID path에 coachingId가 있는 API path variable을 long으로 변환할 수 없습니다.
413 PAYLOAD_TOO_LARGE POST /api/v1/coachings 업로드 영상 또는 multipart 요청이 100MB를 초과했습니다.
404 COACHING_NOT_FOUND 메시지, 진단, 평가 API 요청한 코칭 ID가 존재하지 않습니다.
409 WAITLIST_ALREADY_REGISTERED POST /api/v1/waitlist 이미 사전 등록된 이메일입니다.
409 COACHING_NOT_READY_FOR_MESSAGE 메시지 API 코칭 상태가 QUESTION_READY 또는 IN_CONVERSATION이 아닙니다.
409 COACHING_NOT_READY_FOR_DIAGNOSIS 진단 API 코칭 상태가 READY_FOR_DIAGNOSIS가 아닙니다.
409 COACHING_NOT_EVALUABLE 평가 API 코칭 상태가 COMPLETED가 아닙니다.
409 COACHING_EVALUATION_ALREADY_EXISTS 평가 API 이미 평가가 등록된 코칭입니다.

502 AI_DIAGNOSIS_FAILED 진단 API AI 최종 진단 중 예외가 발생했습니다.
504 AI_ANALYSIS_TIMEOUT 코칭 생성 API AI 초기 분석이 제한 시간 안에 끝나지 않았습니다.
504 AI_CONVERSATION_TIMEOUT 메시지 API AI 대화 질문 생성 또는 대화 충분성 판단이 제한 시간 안에 끝나지 않았습니다.
504 AI_DIAGNOSIS_TIMEOUT 진단 API AI 최종 진단이 제한 시간 안에 끝나지 않았습니다.
