Acttub Backend 전체 API 명세

현재 구현된 Spring MVC Controller, DTO, Service 검증 로직, 전역 예외 핸들러, 통합 테스트를 기준으로 정리한 API 계약입니다. 이 문서는 feature/SOMA-152-chatbot-acting-diagnosis-impl 브랜치 기준입니다.

Base URL: http://localhost:8080 응답 포맷: JSON 문서 기준일: 2026-06-28

목차

  • 공통 규칙
  • 공통 스키마
  • POST /api/v1/coachings
  • POST /api/v1/coachings/{coachingId}/diagnosis
  • POST /api/v1/coachings/{coachingId}/evaluation
  • 오류 코드 목록
  • 현재 미구현 API

공통 규칙

  • 성공 응답은 항상 {"data": ...} 래퍼를 사용합니다.
  • 오류 응답은 항상 {"error": {"code", "message", "details"}} 래퍼를 사용합니다.
  • ID 필드는 응답에서 문자열로 내려갑니다. 예: "coachingId": "1"
  • 시간 필드는 OffsetDateTime으로 직렬화됩니다. 예: 2026-06-28T02:10:00+09:00
  • CoachingResponse는 null 필드를 JSON에서 생략합니다.
  • 문자열 입력은 도메인 모델에서 앞뒤 공백을 제거합니다. 빈 문자열 또는 공백 문자열은 대부분 null 또는 유효하지 않은 값으로 처리됩니다.

성공 응답 래퍼

{
  "data": {}
}

오류 응답 래퍼

{
  "error": {
    "code": "ERROR_CODE",
    "message": "Error message.",
    "details": {}
  }
}

코칭 상태값

상태 의미 클라이언트 동작
ANALYZING 코칭 생성 후 영상 저장 또는 AI 초기 분석 중인 내부 상태입니다. 일반 성공 응답으로는 노출되지 않습니다.
QUESTION_READY AI 초기 분석이 끝났고 사용자가 챗봇 질문에 답변해야 하는 상태입니다. /diagnosis에 답변을 제출합니다.
COMPLETED 최종 진단과 피드백 카드가 생성된 상태입니다. 평가 등록이 가능합니다.
FAILED 영상 저장, 초기 분석, 최종 진단 중 실패한 상태입니다. 진단 또는 평가를 진행할 수 없습니다.

엔드포인트 요약

Method Path Content-Type 성공 HTTP 설명
POST /api/v1/coachings multipart/form-data 201 영상과 장면 정보를 업로드하고 초기 분석 질문을 생성합니다.
POST /api/v1/coachings/{coachingId}/diagnosis application/json 201 초기 질문에 대한 답변을 제출하고 최종 진단을 생성합니다.
POST /api/v1/coachings/{coachingId}/evaluation application/json 201 완료된 코칭 결과에 사용자 평가를 등록합니다.

공통 스키마

CoachingResponse

필드 타입 노출 조건 설명
coachingId string 항상 코칭 ID입니다.
status string 항상 QUESTION_READY, COMPLETED 등 코칭 상태입니다.
createdAt string date-time 항상 코칭 생성 시각입니다.
completedAt string date-time 최종 진단 완료 후 진단 완료 시각입니다.
input object 항상 사용자가 최초 입력한 장르, 상황, 인물 설정, 서브텍스트입니다.
dialogue object 초기 분석 성공 후 챗봇이 사용자에게 물어볼 질문입니다. 현재 DTO에는 question만 포함됩니다.
context object 초기 분석 성공 후 대본, AI 초기 분석, 수치화 가능한 신호, 주관적 진단 가설입니다.

result object 최종 진단 완료 후 최종 피드백 카드입니다.

POST/api/v1/coachings

연기 영상과 장면 맥락을 업로드해 추가 진단 질문을 포함한 QUESTION_READY 코칭을 생성합니다.

요청

항목 값
Content-Type multipart/form-data
파일 크기 제한 100MB, 104857600 bytes
허용 영상 MIME type video/mp4, video/quicktime, video/webm

iPhone 기본 카메라 영상은 보통 .MOV 파일이며 MIME type은 video/quicktime으로 들어옵니다. Android 기본 카메라 영상은 보통 .mp4 파일이며 MIME type은 video/mp4로 들어옵니다.

필드 타입 필수 검증/정규화
video file 예 크기가 0보다 커야 하고, MIME type은 허용 목록 중 하나여야 합니다.
genre string 예 연극, 영화, 뮤지컬, 드라마, 기타 중 하나입니다.
customGenre string 조건부 genre=기타일 때 필수입니다. 장르가 기타가 아니면 서버에서 null로 정규화합니다.
situation string 예 장면 상황입니다. 앞뒤 공백 제거 후 빈 값이면 유효하지 않습니다.
characterSetting string 예 인물 설정입니다. 앞뒤 공백 제거 후 빈 값이면 유효하지 않습니다.
subtext string 아니오 서브텍스트입니다. 생략, 빈 문자열, 공백 문자열은 null로 정규화됩니다.

요청 예시

curl -X POST http://localhost:8080/api/v1/coachings \
  -F "video=@scene.mp4;type=video/mp4" \
  -F "genre=영화" \
  -F "situation=헤어진 연인을 우연히 다시 만난 상황" \
  -F "characterSetting=감정을 쉽게 드러내지 않는 배우 지망생" \
  -F "subtext=아직 미련이 있지만 괜찮은 척한다"

요청

항목 값
Content-Type application/json
Path variable coachingId: long
필드 타입 필수 검증/정규화
answer string 예 진단 질문에 대한 사용자 답변입니다. 앞뒤 공백 제거 후 빈 값이면 유효하지 않습니다.

진단 API는 QUESTION_READY 상태에서 한 번만 성공합니다. 성공 후 상태는 COMPLETED가 되고, 같은 코칭에 다시 진단을 요청하면 COACHING_NOT_READY_FOR_DIAGNOSIS가 반환됩니다.

오류 응답

HTTP code message details 예시 조건
400 INVALID_DIAGNOSIS_REQUEST Invalid diagnosis request. {"fields":["body"]}, {"fields":["answer"]} 요청 본문이 없거나 JSON으로 읽을 수 없거나, answer가 없거나 공백입니다.
400 INVALID_COACHING_ID Invalid coaching id. {"coachingId":"abc"} coachingId path 값이 long으로 변환되지 않습니다.
404 COACHING_NOT_FOUND Coaching not found. {"coachingId":"999999"} 해당 ID의 코칭이 없습니다.
409 COACHING_NOT_READY_FOR_DIAGNOSIS Coaching is not ready for diagnosis. {"coachingId":"1","status":"COMPLETED"} 코칭 상태가 QUESTION_READY가 아닙니다.
415 UNSUPPORTED_MEDIA_TYPE Unsupported media type. {"contentType":"text/plain"} application/json이 아닌 요청입니다.
502 AI_DIAGNOSIS_FAILED Coaching diagnosis failed. {"coachingId":"1","status":"FAILED"} AI 최종 진단 중 예외가 발생했습니다. 실패한 코칭은 FAILED로 저장됩니다.
503 AI_DIAGNOSIS_UNAVAILABLE Coaching diagnosis is unavailable. {"coachingId":"1","status":"QUESTION_READY"} 현재 등록된 AI 분석기가 최종 진단 기능을 지원하지 않습니다. 상태는 실패로 변경하지 않습니다.
504 AI_DIAGNOSIS_TIMEOUT Coaching diagnosis timed out. {"coachingId":"1","status":"FAILED"} AI 최종 진단이 제한 시간 안에 끝나지 않았습니다. 실패한 코칭은 FAILED로 저장됩니다.

POST/api/v1/coachings/{coachingId}/evaluation

완료된 코칭 결과에 사용자 평가를 등록합니다. 코칭 하나당 평가는 한 번만 등록할 수 있습니다.

요청

항목 값
Content-Type application/json
Path variable coachingId: long
필드 타입 필수 검증/정규화
rating integer 예 1 이상 5 이하입니다.
comment string 아니오 null, 빈 문자열, 공백 문자열은 저장/응답 시 null로 정규화됩니다.

요청 예시

curl -X POST http://localhost:8080/api/v1/coachings/1/evaluation \
  -H "Content-Type: application/json" \
  -d '{
    "rating": 4,
    "comment": "감정 흐름은 좋았고 발성 조언은 더 구체적이면 좋겠습니다."
  }'

201 응답

{
  "data": {
    "evaluationId": "1",
    "coachingId": "1",
    "rating": 4,
    "comment": "감정 흐름은 좋았고 발성 조언은 더 구체적이면 좋겠습니다.",
    "createdAt": "2026-06-28T02:12:00+09:00"
