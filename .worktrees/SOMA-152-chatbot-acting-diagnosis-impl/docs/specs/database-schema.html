SOMA-122 · PostgreSQL · Flyway V1-V9 기준

Acttub Backend 테이블 구조

코칭 생성 요청, 업로드 영상 메타데이터, AI 코칭 카드 응답, 사용자 평가를 저장하는 현재 DB 구조입니다. 문자열 컬럼은 길이 제한 없이 text를 사용하고, 카드형 응답은 V8부터 정규화 테이블에 저장합니다.

관계 요약

current write model
coachings 코칭 요청, 영상 메타, AI 메타, 전체 강점, 상태
coaching_feedback_cards 카드형 피드백의 각 카드
coaching_feedback_observations 카드 안의 관찰 근거 목록
coaching_practice_steps 카드 안의 연습 단계 목록
coaching_evaluations 완료된 코칭에 대한 사용자 평가

Legacy 결과 컬럼

compatibility

coachings에는 result_scene_intent, result_focus_*, result_next_step_* 같은 이전 결과 구조 컬럼이 아직 남아 있습니다. 현재 쓰기 로직은 호환 목적으로 첫 번째 카드의 일부 값을 이 컬럼에도 채웁니다. 새 카드형 응답을 복원할 때는 result_overall_strength_text와 V8 정규화 테이블을 기준으로 봅니다.
